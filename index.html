Project Information

This project is an ESP32-based single-phase smart multifunction meter designed to monitor electrical parameters in real time. The system combines electrical measurement, IoT connectivity, data logging and equipment condition monitoring. The collected electrical data can be analysed to identify load characteristics and detect abnormal operating conditions.
